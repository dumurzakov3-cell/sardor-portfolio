# SARDOR — Personal Portfolio

> **Full-stack dasturchi va UI/UX dizayner** shaxsiy portfolio sayti.  
> React.js + Tailwind CSS v4 bilan qurilgan, Vercel'da joylashtirilgan.

🌐 **Live Demo:** [sardor-portfolio.vercel.app](https://sardor-portfolio.vercel.app)

## 📂 Loyiha strukturasi

```
sardor-portfolio/
├── public/
├── src/
│   ├── components/
│   │   ├── AmbientBg.jsx    — Foniy glow elementlar
│   │   ├── Navbar.jsx       — Sticky header navbar
│   │   ├── Hero.jsx         — Hero bo'limi
│   │   ├── About.jsx        — Men haqimda
│   │   ├── Services.jsx     — Xizmatlar
│   │   ├── Projects.jsx     — Loyihalar portfelyo
│   │   ├── Testimonials.jsx — Mijozlar fikri
│   │   ├── Contact.jsx      — Bog'lanish formasi

│   │   └── MobileNav.jsx    — Mobil quyi navigatsiya

│   ├── main.jsx
│   └── index.css            — Tailwind v4 + custom CSS
├── index.html
├── vite.config.js
├── vercel.json
└── package.json
```

## 🛠️ O'rnatish va ishga tushirish

```bash
# 1. Loyihani klonlash
git clone https://github.com/YOUR_USERNAME/sardor-portfolio.git
cd sardor-portfolio

# 2. Paketlarni o'rnatish
npm install

# 3. Development serverini ishga tushirish
npm run dev

# 4. Production build
npm run build
```
